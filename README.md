How To Use:
1. Click the green code button >> download as zip
2. Unzip the zip into a folder
3. Navigate to chrome://extensions
4. Toggle on developer mode with the slider in the top right
5. Click load unpacked in the top left
6. Navigate inside of the folder krillion-ai-main
7. Click open
8. Navigate to either https://krillion.io or https://playdaily.org/krillion
9. Click the K icon in the top right in the pinned extensions
10. Paste in your API key from any AI (for Gemini, navigate to Google AI Studio, sign up, click dashboard in the left panel, click API keys, create new, then copy it)
11. Click dive and the AI will automatically start working (it might not work as well for puffer party or multiplayer)
